# AcloudguruOpsworks

## About This Repository

This repository is a demo/tutorial project for learning and practicing **AWS OpsWorks** deployment with A Cloud Guru. It contains a simple PHP web application designed to be deployed to AWS OpsWorks as part of a hands-on learning exercise.

## What's Inside

- **index.php** - A simple PHP web application that displays:
  - A welcome message
  - The hostname of the server it's running on
  - The PHP version being used
  - A Cloud Guru branding

## Purpose

This repository is designed to help you:
- Learn how to deploy applications to AWS OpsWorks
- Practice creating stacks and layers in OpsWorks
- Understand how PHP applications run in the OpsWorks environment
- See real-time server information to verify your deployment

## Deployment

This application is meant to be deployed to AWS OpsWorks, where it will:
1. Run on an OpsWorks stack and layer
2. Display dynamic server information
3. Confirm successful deployment with a congratulations message

## Technology Stack

- **Language**: PHP
- **Platform**: AWS OpsWorks
- **Purpose**: Educational/Tutorial
